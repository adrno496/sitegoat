# Sitegoat V9 — guide utilisateur

V9 désigne cette interface et son intégration éditoriale ; la version applicative est 2.1.0. Les documents V7 conservent leur format et leur autonomie.

1. **Importer une édition** : choisir le HTML UTF-8, examiner les informations puis enregistrer. Un seul fichier cumulatif tardif suffit pour les articles, l’économie, les jalons, les prompts et les brèves réellement embarqués. Les anciennes journées et les originaux antérieurs restent conservés.
2. **Accueil** : consulter jusqu’à six points essentiels issus des importations, les changements déclarés, les signaux conditionnels et les rubriques. La dernière actualisation indique l’heure d’import locale, pas la date des événements. Un graphique n’apparaît qu’avec au moins deux points officiels comparables ; sinon l’état « Historique insuffisant » explique la limite.
3. **Aujourd’hui** : ouvrir les rubriques À la une, Économie, IA majeures, Chronologie IA, SENTINEL & AXDIA, Le Futur ou Actualité rapide. Les cartes offrent un aperçu de deux phrases au plus lorsque le texte source est ponctué, Développer et la lecture interne de l’article. Les détails restent intégralement conservés.
4. **Lire la dernière édition** : ouvrir le document original dans le lecteur isolé. Pour un HTML unifié dynamique, choisir « Afficher le HTML d’origine » puis confirmer la confiance pour cette visite. Sa mise en page, ses filtres et accordéons sont conservés. Les liens publics et les téléchargements Markdown demandés par le document sont confirmés dans le site ; aucune permission d’accès au compte ou au stockage parent n’est donnée au HTML.
5. **Actualité rapide** : rechercher un titre, filtrer les thèmes réellement disponibles, choisir un statut ou trier. Les titres ne sont pas des articles longs. Les promotions sont masquées du compteur courant pour éviter un double comptage, puis consultables avec leur filtre. Les 19 titres du fichier fourni sont ceux présents dans ses octets ; le site n’en fabrique pas pour atteindre un quota. Les statuts et sources sont déclarés par le producteur, pas revérifiés par le site.
6. **Articles** : recherche plein texte, filtres combinables rubrique/univers/preuve/importance/dates du fait/lecture/veille, tri et présentation thèmes/calendrier/chronologie ; 30 cartes par page. Ouvrir l’article interne pour lire résumé, analyse, limites, sources et corrections disponibles. L’index permet aussi d’ouvrir l’original.
7. **Recherche Google** : clic volontaire, nouvelle fenêtre sans opener ni referrer. Seule la question déclarée publique est encodée. Sans question sûre, Google s’ouvre sans texte. Les notes et prompts ne sont jamais utilisés pour composer la recherche. Le Mode IA historique reste facultatif et passe par ses contrôles existants ; aucun préremplissage IA n’est promis.
8. **Paramètres > Affichage** : densité, animations, cartes ou liste, graphiques, détails, actions secondaires, sections Accueil/Aujourd’hui et catégories favorites. Les réglages sont locaux, réinitialisables et appliqués pour la session si leur enregistrement échoue. Le thème clair/sombre reste disponible. Les anciens profils sont accessibles dans « Profils et options historiques ».
9. **Paramètres > Avancé · Diagnostic des imports** : inspecter intégrité, autonomie, couverture, historique, révisions, provenance et créneaux. Un créneau n’ouvre que son original réellement reçu ; un créneau couvert dans un cumul peut afficher « Édition originale non importée ». L’historique complet reste dans Bibliothèque, via « Autres espaces ».
10. **Sauvegarder** : exporter le ZIP depuis les paramètres ; Le Futur garde sa sauvegarde indépendante. Le ZIP protège les documents et états de lecture, pas les préférences d’affichage du navigateur. « Original intact » télécharge les octets HTML initiaux. Ne pas effacer les données du navigateur pour actualiser l’application ; utiliser l’avis de mise à jour PWA.

Navigation principale : Accueil, Aujourd’hui, Articles, Paramètres. « Autres espaces » conserve Bibliothèque, Rechercher, Mémoire, IA majeur, Sentinel et Le Futur. L’ouverture initiale reste Aujourd’hui pour préserver le comportement des installations et liens existants. Le bouton de marque ouvre désormais Accueil.

Limites : un document dynamique exige une confiance explicite pour ses scripts. Ressources externes, stockage intégré, formulaires réseau et navigation du parent restent bloqués ; la copie affichée reçoit les protections CSP/sandbox. Le téléchargement original conserve toujours le fichier exact. Les sources sur Internet et Google nécessitent une connexion. Un script activé peut encore naviguer son propre cadre : activer uniquement les fichiers dont vous connaissez le producteur. Le producteur automatique, la collecte et son registre ne sont pas inclus dans cette mise à jour.

La notice du compagnon est conservée telle qu’importée. Une mention historique « Import Sitegoat NON TESTÉ » du producteur ne remplace pas les résultats applicatifs du rapport de tests V9.

Pour les prompts qui dépassent 200000 octets ou les téléchargements propres à un producteur non reconnus par le lecteur, utilisez Mes prompts .md dans le site, ou Original intact. Le relais natif du cadre ne traite que les Markdown reconnus sous cette limite.
